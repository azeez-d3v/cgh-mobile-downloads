# CGH Mobile Downloads

Public download page and release repository for the unofficial CGH Mobile Android application.

- Website: <https://azeez-d3v.github.io/cgh-mobile-downloads/>
- APK releases: <https://github.com/azeez-d3v/cgh-mobile-downloads/releases>
- Direct latest APK: <https://github.com/azeez-d3v/cgh-mobile-downloads/releases/latest/download/CGH-Mobile.apk>

The application source code is maintained separately in a private repository. This public repository contains only the static download website and public APK release artifacts.

CGH Mobile is an independent, unofficial, read-only student portal companion. It is not affiliated with, operated by, or endorsed by CGH or SchoolAutomate.
