Direct installation

Install the APK in 3 Steps.

Portal is distributed through GitHub Releases, not the Play Store.

  1. 1
    Download the APK

    Select Download Latest APK and keep the file on your Android device.

  2. 2
    Allow This Source

    If Android asks, allow your browser or file manager to install this APK.

  3. 3
    Install & Sign In

    Open Portal and use only your own authorized student portal account.

Verify Your Download

Every production release includes a SHA-256 checksum beside the APK. Compare it before installing if you want to verify the file.

Transparent by design

Know Where Your Data Goes.

Production sign-in and record requests go directly to the official portal. Passwords are not intentionally persisted. Previously retrieved records may remain in private app storage for offline viewing.
